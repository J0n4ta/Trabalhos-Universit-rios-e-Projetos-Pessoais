# Trabalhos-Universit-rios-e-Projetos-Pessoais
Neste repositório estão alguns trabalhos da minha faculdade UFCI-RJ (CEFET-RJ), além de projetos pessoais, onde ambos englobam Machine Learning, Deep Learng, Computer Vision e outros. Além disso, para cada código possui uma explicação bem breve sobre o funcionamento do algoritmo.

O repositório foi criado no dia 14/11/2026, com intuito de demostrar o conhecimento adquirido por min e propagá-lo de forma simples para o público que possui interesse nesse âmbito de programação de aprendizado de maquina e outros temas. Além disso, a criação desse repositório também ajuda a guardar trabalhos e projetos, de tal forma que não haja uma perda desses materiais, assim criando um arranjo simples para min e o público
